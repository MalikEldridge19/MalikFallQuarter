1. What is Git, what is Github, and what is the difference between the two? Git is a VCS that tracks the changes in source code. Github is an online platform made for storing tracking projects files. The difference is Git tracks changes in source code, while Github tracks project files.
2. What is the difference between a local repository and a remote repository? Local repository is repos on the device, while remote repository is where the repos go.
3. What does the push command do in Git? Upload your files into the cloud to the remote repo.
4. What does the commit command do in Git? Saves your changes in the repo.
5. What is Github Desktop, & why are we using it? A desktop app used to be easier enough to use more than both Github.com and Git.
